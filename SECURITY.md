# Reporting a security problem

If you find a way to get a private, local or reserved address past `safe-url`, please don't open a public issue. Email **team@codyza.com** with:

- the input (URL, hostname or IP) that gets through,
- which function you used (`checkUrl`, `isPublicAddress`, `safeFetch`, `publicLookup`),
- your Node version.

We'll reply within a few days, fix it, and credit you in the release notes if you'd like.
